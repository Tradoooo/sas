# Media — what the video and the site use, and what is still missing

This directory is the inventory of the **visual** material of the submission.
Everything listed here is either already in the repository or produced by a
command in it; nothing is a placeholder for something that does not exist.

The video itself is **not** here yet — the script is, the recording is not
(`docs/ECHECS.md` §8). See "Still to produce" at the end.

Both SVGs are **hand-written**: no `<script>`, no `@import`, no remote font, no
external image. They parse as XML, carry an explicit `viewBox`, and every text
is at least 11 px — legible when they are scaled to 1200 px wide and when they
are projected. The colour is never the only carrier of meaning: every block is
labelled in words.

`tests/unit/docs/test_narratif.py` guards all of that, so the two images cannot
quietly lose a `viewBox`, gain a remote resource, or fall below the readable
size.

## 3. What the images carry, and what they refuse to carry

Both infographics are **factual and labelled**, like every other deliverable of
this dossier:

- `infographie-canal.svg` closes on the limits — the statistical bound, shadow
  mode and real data, fine covert channels, the non-instrumentable agent — and
  on the sentence that the sponsor alone decides to go live.
- `infographie-approches.svg` closes on the boundary of the portfolio
  (`rempart` attacks the application, `piege` attacks the assistant, **Sas
  hosts the invited agent and measures it**) and on what Sas does **not**
  replace: the vendor's SOC 2 report, the code review, the MFA.

Every figure printed on them is measured by the repository — `100 %` journal
coverage, `0.82 $` per homologation, the `9` forbidden compositions on the
curious guest, the `98 %` / `82 %` published bound. Sources:
`portal/data/demo.json`, `docs/ECHECS.md` §4, `src/sas/statistiques.py`.

## 6. Naming and placement rules

- A visual asset lives in `docs/narratif/` (diagrams and narrative) or in
  `portal/` (what the public site serves). Nothing else is added to the root.
- Every asset carries a `<title>` and a `<desc>`: they are what a screen
  reader announces, and what the Devpost alt-text is copied from.
- No remote font, no CDN, no `@import`, no script: the submission must render
  with the network off.
- Any figure printed on a visual asset must be traceable to the repository —
  `tests/unit/docs/test_narratif.py` refuses a number that no file of the
  repository contains.
